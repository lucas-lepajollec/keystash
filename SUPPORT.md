# Support

## Where to Get Help

- **Documentation**: Read the [README.md](README.md) for installation, configuration, and Docker Compose examples.
- **Bug Reports**: If you encounter a bug or unexpected behavior, open an issue using the [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.md).
- **Feature Requests**: If you have an idea that fits the minimalist, calm spirit of KeyStash, open a [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md).
- **Security Inquiries**: See [SECURITY.md](SECURITY.md) for private vulnerability reporting.
